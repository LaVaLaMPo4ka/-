# Azatara Site — final (frontend-only)

Исправленная версия: восстановлены разделы 'Возможности' и 'Новости' на главной странице, добавлена увеличенная кнопка Discord, улучшена стабильность сохранения в localStorage.

Ключевые изменения:
- LocalStorage записывается прямо в функции-мутаторы (add/update/delete), чтобы исключить перезапись пустыми значениями при монтировании.
- Обработчики для правил и описания сразу сохраняют в localStorage.
- Пульсация фона стала плавной и имеет небольшую рандомизацию длительностей/задержек.
- Увеличенная кнопка Discord под заголовком (класс `.btn-discord-large`).

Запуск:
1. `npm install`
2. `npm run dev`
3. Открыть http://localhost:5173

Если при добавлении больших изображений localStorage не вмещает — браузер выдаст alert об ошибке сохранения. Рекомендую для производства подключить внешний бэкенд/хранилище для медиа.
